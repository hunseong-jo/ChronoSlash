# CHRONO SLASH (크로노 슬래시)

> **"내가 움직일 때만 시간이 흐른다."**  
> HTML5 Canvas 2D + Web Audio API 기반의 시간 정지 택티컬 네온 액션 웹 게임

---

## 실행 방법
별도의 설치나 빌드 과정 없이 **`index.html` 파일을 브라우저(Chrome / Edge / Safari 등)로 더블클릭**하면 바로 실행됩니다.

---

## 핵심 조작법
| 입력 | 동작 |
| :--- | :--- |
| **`WASD` / `방향키`** | 이동 (이동할 때만 시간이 정상 속도 `1.0x`로 흐르며, 멈추면 `0.035x` 초슬로우) |
| **`마우스 좌클릭` / `SPACE`** | 커서 방향으로 **대시 베기** (적 처치 및 탄환 패링, 성공 시 쿨타임 즉시 초기화) |
| **`마우스 우클릭` / `SHIFT`** | 제자리에서 **시간만 흘려보내기** (탄환 타이밍 조절용) |
| **`R`** | 즉시 스테이지 재시작 |
| **`ESC`** | 일시정지 / 메뉴 |
| **`M`** | 오디오 음소거 토글 |

---

## 핵심 기획 & 시스템 포인트
1. **단일 코어 메카닉(Time-Moves-When-You-Move):**
   * 플레이어 입력 여부에 따라 물리 시뮬레이션 `timeScale`(`0.035x ~ 1.0x`)과 배경 오디오 로우패스 필터가 실시간으로 연동됩니다.
2. **리스크-리턴 연쇄 액션 (Dash Reset & Parry):**
   * 적 처치 또는 날아오는 탄환 **패링(반사)** 성공 시 대시 베기 쿨타임이 즉시 초기화되어 스타일리시한 연쇄 처치가 가능합니다.
3. **10단계 에스컬레이션 레벨 디자인 & 보스전:**
   * 6종의 일반 적(가드, 산탄 헤비, 레이저 스나이퍼, 점사, 근접 블레이드, 정면 방패, 자동 포탑)과 10스테이지 멀티 페이즈 보스 **`CHRONOS WARDEN`**으로 구성되어 있습니다.
   * 시연·평가 편의를 위해 스테이지 선택 화면에서 전 10개 스테이지에 바로 진입할 수 있습니다.
4. **제로 에셋(Zero-Asset) 웹 아키텍처:**
   * 외부 이미지·음원 의존성 없이 Canvas 2D 벡터/글로우 렌더링, 히트스톱(Hitstop), 화면 흔들림, 잔상, 바닥 데칼, Web Audio API 절차적 사운드로 구현했습니다.
